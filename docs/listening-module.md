# Модуль «Прослушка»

Модуль для выбора того, что слушать в дороге. Реализует ту же циклическую механику, что описана в `core-cycle-logic.md`, и, как «Чтение» (`reading-module.md`), добавляет текстовое поле-уточнение к каждой отметке — но с одним отличием: поле **не предзаполняется** (см. раздел 2 ниже и раздел 8 `core-cycle-logic.md`).

## 1. Цикл модуля

Цикл состоит из 8 слотов, без повторов — каждый пункт встречается в цикле один раз, в указанном порядке.

| # | Активность |
|---|---|
| 1 | Шульман |
| 2 | КАП |
| 3 | Easy German |
| 4 | Подготовка к концерту |
| 5 | Лекции Ивана Соколова |
| 6 | Канал Ирины Якутенко |
| 7 | Тренер Ирина Ковалёва |
| 8 | Разное (Саша Грибанов, Мария Плескачёва и др.) |

Базовый алгоритм выбора следующей активности — без изменений (раздел 3 `core-cycle-logic.md`): после отметки слота №8 («Разное…») цикл начинается заново со слота №1 («Шульман»).

## 2. Текстовое поле-уточнение (без предзаполнения)

При отметке любой активности этого модуля пользователю доступно текстовое поле «уточнение» (например, номер/название конкретного выпуска).

- Поле необязательно: отметка выполнения проходит и с пустым уточнением.
- **В отличие от «Чтения», поле не предзаполняется** прошлым текстом для того же названия активности: при каждой отметке поле открывается пустым, пользователь вводит уточнение заново (или оставляет пустым). Это управляется флагом `notePrefill: false` в определении модуля — общий механизм описан в разделе 8 `core-cycle-logic.md`.
- В лог уточнение попадает как обычный снимок на момент отметки (`note`), как и в любом модуле с текстовым полем.

## 3. Лог

Каждая запись лога модуля «Прослушка» содержит:
- вид активности (`title`, снимок названия слота на момент отметки),
- текстовое уточнение (`note`, снимок на момент отметки, может быть пустым),
- дату и время отметки.

Как и в «Чтении», в списке лога отображаются дата **и время** отметки (`showTime: true`).

## 4. Редактирование цикла

Состав и порядок цикла редактируются через интерфейс, как и в остальных модулях: активности можно добавлять, удалять и переставлять местами. Стартовый цикл — список из 8 слотов, приведённый в разделе 1.

## 5. Место в списке модулей

«Прослушка» — последний пункт в списке модулей приложения, после «Активности».

Открытые вопросы из `core-cycle-logic.md` (раздел 12) — про удалённую из цикла последнюю активность, уведомления, синхронизацию и редактирование лога задним числом — распространяются и на этот модуль; отдельных решений для «Прослушки» не требуется, они общие для приложения.
