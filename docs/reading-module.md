# Модуль «Чтение»

Второй модуль приложения, реализующий ту же циклическую механику, что описана в `core-cycle-logic.md`, но с добавлением необязательного текстового поля-уточнения к каждой отметке (см. раздел 8 того документа).

## 1. Цикл модуля

Цикл состоит из 13 слотов. Названия могут повторяться — это разные слоты одного цикла с разными `id`, но общим текстом уточнения (раздел 2 и раздел 8 `core-cycle-logic.md`).

| # | Активность |
|---|---|
| 1 | Другое вечера |
| 2 | Книга |
| 3 | МЖ и Opernwelt |
| 4 | Программки / 2 Read в метро / Telegram |
| 5 | Рабочее |
| 6 | AI-беседы и вопросы |
| 7 | Книга |
| 8 | МЖ и Opernwelt |
| 9 | Программки / 2 Read в метро / Telegram |
| 10 | Другое вечера |
| 11 | Книга |
| 12 | Другое вечера |
| 13 | Книга |

Базовый алгоритм выбора следующей активности — без изменений (раздел 3 `core-cycle-logic.md`): после отметки слота №13 («Книга») цикл начинается заново со слота №1 («Другое вечера»).

## 2. Текстовое поле-уточнение

При отметке любой активности этого модуля пользователю доступно текстовое поле «уточнение» (например, название книги для активности «Книга»).

- Поле необязательно: отметка выполнения проходит и с пустым уточнением.
- Поле предзаполняется текстом из самой последней по времени записи лога с тем же названием активности (`title`), независимо от того, в каком из слотов цикла это название встречалось. Например, текст, введённый для «Книга» в слоте №2, предзаполнит поле в следующий раз, когда наступит очередь «Книга» — будь то слот №7, №11 или №13.
- Пользователь может оставить предзаполненный текст как есть или заменить его — новое значение становится значением для предзаполнения при следующей встрече этого названия.
- В лог уточнение попадает как неизменяемый снимок на момент отметки; более позднее редактирование текста для этого названия не меняет уже созданные записи лога задним числом.

## 3. Лог

Каждая запись лога модуля «Чтение» содержит:
- вид активности (`title`, снимок названия слота на момент отметки),
- текстовое уточнение (`note`, снимок на момент отметки, может быть пустым),
- дату и время отметки.

В отличие от MVP-модуля «Языки», где в истории показывается только дата, в этом модуле в списке лога отображаются дата **и время** отметки.

## 4. Редактирование цикла

Как и в модуле «Языки», состав и порядок цикла редактируются через интерфейс: активности можно добавлять, удалять и переставлять местами. Стартовый цикл — список из 13 слотов, приведённый в разделе 1.

Открытые вопросы из `core-cycle-logic.md` (раздел 9) — про удалённую из цикла последнюю активность, уведомления, синхронизацию и редактирование лога задним числом — распространяются и на этот модуль; отдельных решений для «Чтения» не требуется, они общие для приложения.
